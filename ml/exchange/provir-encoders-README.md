# Provir encoder set — shared 2026-08-21

Every encoder binary we may redistribute, as measured in our emitter register and idem probe map.
Layout: <Family>/<register label>/ (the label = era_encoders/<label> in our tree). Build identity (sha256, PE build date, banner)
for every rung is in _records/; SHA256SUMS.txt covers every file here. Three builds were compiled by us
from source on 2026-08-21 (lame3.94b, lame3.95, lame4.0) — build date != source date, stated in the identity
file with the one portability guard applied. Restricted encoders are in MANIFEST_RESTRICTED.md with
where to get identical bytes. Mechanism, not calibration: no fitted thresholds are in this folder.
