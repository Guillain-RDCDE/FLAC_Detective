# History

Dated records kept for the project's history: replies and notes from the blind
exchange with Provir, the species census, the Set C proposal, and drafts of
replies to GitHub issues.

They are working records, not documentation. They read as of their date, are
not kept up to date, and are excluded from the published documentation site
(`exclude_patterns` in `docs/conf.py`). For how the tool works today, start at
[the documentation index](../index.md).
